# ADR-0003：指标默认关闭并限制为低基数标签

- 状态：Accepted
- 日期：2026-07-27

## 背景

个人部署也需要发现错误率、异常延迟和不可用状态，但公开指标可能泄露部署细节，并且带用户、
书名、文件名或书籍 ID 的标签会使监控系统的时间序列无界增长。

## 决策

应用以无额外 SDK 的方式记录 HTTP 与固定操作名指标。指标只使用方法、路由模板、状态码和
预定义操作名等低基数标签，不包含用户或书籍相关标识。只有
`METRICS_ENABLED=true` 时才注册 `/metrics`，并且 Caddy 不代理该端点。

## 后果

- Prometheus、Grafana 和告警可在内网部署，而默认公网暴露面不扩大。
- 备份失败、磁盘空间和外部可用性不伪装成应用指标，应由日志、Node Exporter 和 Blackbox
  Exporter 等适当采集器处理。
- 新增指标必须先评估标签基数和是否可能携带用户数据。
