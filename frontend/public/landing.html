01 · 核心功能

为深度阅读者而生。

  1. 全格式支持EPUB, MOBI, AZW3, PDF

    统一管理你的所有电子藏书。导入即自动提取元数据与封面，建立整齐的个人图书馆。

  2. 进度云同步多端续读

    阅读状态实时保存至后端数据库。无论从哪台设备打开，都能立即回到上次停下的行间。

  3. 语音伴读TTS 技术

    支持配置第三方 TTS 服务。当你需要闭上眼睛或正在通勤时，让书籍“读”给你听。

  4. 精细分类标签与排序

    灵活的分类管理系统。支持按作者、系列或自定义标签筛选，让你的书架井然有序。

04 · 常见问题

解决你的疑惑。

如何部署 Z Reader？
最简单的方法是使用 Docker。运行 docker run -d -p 80:80 ghcr.io/zuoban/z-reader 即可启动，首次访问时创建账号。
支持哪些电子书格式？
目前原生支持 EPUB, MOBI, AZW3 和 PDF。对于带 DRM 加密的图书，请先移除加密后再上传。
如何启用 TTS 语音朗读？
你需要在配置文件或环境变量中填入你自己的 TTS 服务凭据（如微软 Azure 或 Google Cloud TTS）。具体步骤请参考文档。
