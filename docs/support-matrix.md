# 支持矩阵

本矩阵区分“已验证”与“预计可用”。除非一项标记为已验证，否则请在自己的设备和书库上先做
试运行；欢迎用 issue 报告实际兼容性结果。

| 状态 | 含义 |
| --- | --- |
| **已验证** | 有 CI、自动化测试或记录的性能基线覆盖 |
| **支持，未完整自动化验证** | 应用代码和依赖支持该能力，但没有对应端到端覆盖 |
| **尽力支持** | 响应式或标准 Web 技术预期可用，尚未在实际目标设备或浏览器验证 |
| **不支持** | 当前架构或发布物不提供该能力 |

## 浏览器与设备

| 平台 | 状态 | 验证范围 | 备注 |
| --- | --- | --- | --- |
| 桌面 Chrome / Chromium | **已验证** | Playwright 功能、可访问性与 Linux 视觉回归 | CI 固定使用 Desktop Chrome |
| Android Chrome | **尽力支持** | 390×844 移动书架视觉快照 | 尚无实体设备或 Android 浏览器 CI |
| iOS Safari | **尽力支持** | 响应式布局设计 | 尚无 Safari CI 或实体设备验证 |
| 桌面 Firefox / Safari | **尽力支持** | 标准 Web API 与响应式布局 | 尚无专门自动化套件 |
| 离线阅读副本 | **已验证** | 前端单元测试与 Service Worker 规则 | 副本按账号隔离，退出登录时清除 |

移动端的“尽力支持”不等于已在所有设备通过验证。遇到阅读器、文件下载或输入法差异时，请附上
设备型号、系统版本、浏览器版本和最小复现步骤。

## 文件格式

| 格式 | 上传与书库 | 阅读路径 | 自动化证据 | 备注 |
| --- | --- | --- | --- | --- |
| EPUB | **已验证** | **已验证** | 真实最小 EPUB 的 Playwright 阅读器 happy path | 推荐的首选格式 |
| PDF | **支持，未完整自动化验证** | **支持，未完整自动化验证** | 无真实 PDF 阅读器 E2E fixture | 请先在目标设备试读 |
| MOBI | **支持，未完整自动化验证** | **支持，未完整自动化验证** | 无真实 MOBI 阅读器 E2E fixture | 兼容性取决于阅读引擎与文件本身 |
| AZW3 | **支持，未完整自动化验证** | **支持，未完整自动化验证** | 无真实 AZW3 阅读器 E2E fixture | 兼容性取决于阅读引擎与文件本身 |

上传格式由后端显式校验；阅读由集成的 foliate-js 与其依赖处理。对于加密、损坏、异常大或使用
厂商私有扩展的文件，不作兼容性承诺。

## 部署方式

| 方式 | 状态 | 验证范围 | 备注 |
| --- | --- | --- | --- |
| Docker Compose（从仓库构建） | **已验证** | CI 校验 Compose 配置；同一镜像通过启动、健康/就绪、Caddy 路由与持久化卷替换 smoke test | 个人和家庭部署的推荐方式 |
| Docker 镜像（GHCR） | **支持，未完整自动化验证** | 发布工作流构建 linux/amd64 与 linux/arm64 镜像、SBOM 与 provenance | 使用明确的发布 tag；尚无 arm64 运行时 smoke test |
| 本地开发（Go + Node.js） | **支持，未完整自动化验证** | 后端、前端单测、构建与 E2E 命令 | 面向贡献者，不是生产部署拓扑 |
| Kubernetes、Docker Swarm | **不支持** | 无部署清单、CI 或运维手册 | 可自行试验，但不承诺升级或恢复路径 |
| 多实例主动—主动部署 | **不支持** | bbolt 与本地上传目录是单写、单主机设计 | 不能共享同一数据目录运行多个实例 |

部署、升级、回滚和备份恢复步骤见[部署与运维手册](operations-runbook.md)。

## 已验证书库规模

| 场景 | 已验证规模 | 证据与限制 |
| --- | ---: | --- |
| 后端书架首屏、摘要、标题搜索 | 1,000 / 10,000 本 | 确定性 bbolt 夹具、排序/搜索/摘要索引和 Go benchmark |
| 后端进度保存（顺序与并发） | 1,000 / 10,000 本 | 100 本活跃书工作集的并发 benchmark |
| 前端虚拟书架 | 分页与虚拟化行为 | Playwright mock API 验证加载、滚动和虚拟化；不是 10,000 本真实端到端基准 |
| 实际上传文件总量与并发用户数 | 未设承诺 | 受磁盘、CPU、文件大小、TTS 配置和网络影响 |

10,000 本是当前**已验证的后端书库规模**，不是所有部署环境的容量保证。性能对比应使用
[性能基线](performance-baseline.md)中相同的 Go 版本、数据规模和命令；准备扩大书库或提高
并发前，请先在自己的硬件上运行基准和 HTTP 核心链路压测。

## 维护规则

新增浏览器、格式、部署方式或规模声明前，必须补充可复现的验证证据，并更新本矩阵。出现兼容性
回归时，应先把状态降为“尽力支持”或“支持，未完整自动化验证”，再评估修复优先级。
