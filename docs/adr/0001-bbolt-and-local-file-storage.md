# ADR-0001：使用 bbolt 与本地文件存储作为单实例持久层

- 状态：Accepted
- 日期：2026-07-27

## 背景

Z Reader 的主要部署场景是个人或家庭书架：数据规模有限、希望一台主机即可运行，且不应因
增加数据库服务和对象存储而提高备份、恢复和升级成本。与此同时，书籍元数据、进度和会话
必须具备事务性和可验证的恢复路径。

## 决策

使用 bbolt 保存书籍元数据、用户、书签、进度和索引；会话使用独立的
`data.db.sessions`，减少会话访问与主库写入的锁竞争。电子书和封面保留在本地
`uploads/`。备份将两个数据库快照和上传文件一起写入带 SHA-256 清单的目录。

## 后果

- 部署、备份与恢复保持为本地文件操作，适合单人维护。
- bbolt 的单写事务和本地文件系统不支持多个应用实例共享同一数据目录；当前不支持
  主动—主动或跨主机写入。
- 数据目录必须使用持久化卷，并在升级前校验备份。恢复只能写入新的空目标，不能原地覆盖。
