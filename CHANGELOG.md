# Changelog

All notable changes to Z Reader are documented in this file.

The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Official releases
use annotated Git tags in the form `vMAJOR.MINOR.PATCH`.

## [Unreleased]

- CodeQL analysis, Dependabot updates, release checklist, and stricter CI quality gates.

### Fixed

- The reader authentication loading visual test now targets its stable accessible status.
